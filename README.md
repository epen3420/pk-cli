# pk-cli

pk (Process Keeper) は tmuxを利用したシンプルなプロセス管理ツール。SSH経由でのMinecraftやARKなどのサーバー起動・管理に最適です。
スクリプトをエイリアスとして登録し、バックグラウンドでの実行やコンソールへのアタッチを簡単に行うことができます。

## 特徴
- シェルスクリプト(`.sh`)をエイリアスとして登録し、短い名前で管理できます。
- 登録したスクリプトを `tmux` セッション内でバックグラウンド実行します。
- 実行中のプロセス(コンソール)へ簡単にアタッチ/デタッチ可能です。
- エイリアス名を省略した場合、インタラクティブにリストから選択して実行・アタッチできます。

## 動作環境
- **Linux専用** (クロスコンパイルの予定はありません)
- `tmux` がシステムにインストールされている必要があります。

## インストール

### GitHub Releasesからダウンロード（推奨）
GitHubのReleasesページから、ビルド済みのLinux向けバイナリをダウンロードしてご利用いただけます。
ダウンロードしたバイナリに実行権限を付与し、パスの通ったディレクトリ（`/usr/local/bin` など）に配置してください。

```bash
chmod +x pk
sudo mv pk /usr/local/bin/
```

### ソースコードからビルドする場合
Rustの開発環境(Cargo)が必要です。リポジトリをクローンし、以下のコマンドでインストールしてください。

```bash
cargo install --path .
```

## 使い方

`pk` コマンドを使用して管理を行います。エイリアス情報は `~/.pk_alias` に保存されます。

### コマンド一覧

#### `register`
シェルスクリプトをエイリアスとして登録します（対象は `.sh` ファイルのみです）。
```bash
pk register <PATH> <ALIAS>
```

#### `run`
登録されたエイリアスのスクリプトを実行し、`tmux` セッション内でバックグラウンド起動します。
エイリアスを省略した場合は、登録済みリストが表示され番号で選択できます。
```bash
pk run [ALIAS]
```

#### `console`
実行中のサーバーのスクリーン(`tmux` セッション)にアタッチします。
アタッチ後、セッションを終了せずに元のシェルに戻る(デタッチする)には `Ctrl+B` の後 `D` を押します。
エイリアスを省略した場合は、現在実行中のセッションリストが表示され、番号で選択してアタッチできます。
```bash
pk console [ALIAS]
```

#### `rename`
登録済みのエイリアス名を変更します。
```bash
pk rename <OLD_ALIAS> <NEW_ALIAS>
```

#### `delete`
登録済みのエイリアスを削除します（元のスクリプトファイル自体は削除されません）。
```bash
pk delete <ALIAS>
```

#### `list`
現在登録されているエイリアスとパスの一覧を表示します。
```bash
pk list
```
